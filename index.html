Instructions

This is a custom VaxCare Pattern Generator, a generative design tool developed for the visual identity. It creates animated, interactive pattern compositions in real time, which can be exported as digital assets for use across project applications.

Patterns

Choose from two pattern types:

  • Circle — Creates soft, connected compositions using the circle as a core visual motif from the VaxCare logo.
  • Plus — Builds on the rounded forms and curves of the existing identity, creating a structured pattern with a softer healthcare feel.

Themes

Switch between Light, Dark, Single Color, and Gradient mode. Use Invert to flip the colors.

Motion

  • Still — Pattern stays in place.
  • Flow — Pattern moves continuously across the canvas in a steady direction.
  • Pulse — Pattern expands and contracts rhythmically, creating a breathing effect.
  • Wave — Pattern moves in a wave-like motion, creating a sense of rhythm and depth.

Controls

  • Speed — Adjust how fast the pattern moves.
  • Density — Control how full or minimal the pattern feels.
  • Spacing — Adjust the distance between pattern elements.
  • Grid — Control the scale of the pattern structure, making the overall composition feel larger or smaller.

Export

  • PNG / JPG — Save a still image.
  • SVG — Export a scalable file.
  • Animation — Record a looping video. Duration matches the natural cycle of each spatial mode.
